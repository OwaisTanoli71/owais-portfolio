## Getting Started

Installation

1. Clone the repository
git clone https://github.com/OwaisTanoli71/owais-ai-portfolio.git
cd owais-ai-portfolio

2. Install dependencies
npm install

3. Configure Environment Variables
Create a .env file in the root folder:
NEXT_PUBLIC_SITE_URL=http://localhost:3000

4. Run the Development Server
npm run dev

Open http://localhost:3000 in your browser.

---

## Available Scripts

npm run dev
Starts Next.js development server with Turbopack

npm run build
Builds optimized production bundle

npm run start
Launches compiled production server

npm run lint
Runs ESLint type and syntax validation

---

## Deploying to Vercel

1. Push your repository to GitHub.
2. Log in to Vercel and click Add New Project.
3. Import your owais ai portfolio repository.
4. Set the Environment Variable NEXT_PUBLIC_SITE_URL to your domain URL.
5. Click Deploy.
